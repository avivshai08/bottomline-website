# Purpose

**Bottom line** is Aviv Shai’s finance-advisory brand. This repo is the public Hebrew website: who he is, what he offers, and how to start a conversation.

## Offers

- **שותף פיננסי** — fractional / outsourced CFO.
- **רווח לפני הכל** — Profit First method, book, and allocation tool.
- **משחקים עסקים** — facilitated business-simulation programs.

Home (`/`) is the About page. Contact is `aviv@bottomline.finance`.

## What we are doing in this repo

The site is a Vite + React rebuild of a Lovable-era design, refined in place: RTL Hebrew, approved illustrations, and a tight visual system. The job is to **finish and maintain that site**, not to start over.

Live: [https://comfy-kleicha-6e4ced.netlify.app](https://comfy-kleicha-6e4ced.netlify.app)

Deploy by building and uploading the **`dist`** folder to Netlify. There is no required git remote.
