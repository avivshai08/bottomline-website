# Docs index

Read **only** what the current task needs. Update the matching file when a decision should survive the next session.

| File | Read when |
| --- | --- |
| [purpose.md](purpose.md) | You need the product goal or audience |
| [workflow.md](workflow.md) | Starting a session, committing, or handing off |
| [constraints.md](constraints.md) | Before any visual, copy, route, or asset change |
| [visual-system.md](visual-system.md) | Type, color, header, CTA, frames, RTL |
| [pages.md](pages.md) | Working on a specific page |
| [development.md](development.md) | Dev server, build, deploy, git, image pipeline |

## Keep these docs small

- Record **decisions**, not a changelog of every pixel.
- If a rule moved, edit the file — do not append a contradiction.
- Page-specific notes belong in `pages.md`, not in `AGENTS.md`.
